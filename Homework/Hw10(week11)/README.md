## 💡 專案緣起：全台年輕人的過年防放槍救星 (Motivation)

逢年過節回老家，長輩親戚缺一咖硬拉你上桌，但新手常常面臨巨大的痛點：

1. **記不住繁瑣牌理**：手牌拿滿 17 張，不知該打哪張，想太久被親戚催促。
2. **極易放槍包大牌**：看不懂場上危險生張，盲目出牌導致放槍輸光過年紅包。
3. **陷入吃碰天人交戰**：跳出按鈕叫我碰，新手根本不知道「該不該按」以及「按了會不會變爛」。

本專案依循**「以使用者為中心（User-Centered Design）」**理念，打造了一套**【麻將新手 AI 智慧副駕駛】**——不需要背牌理，系統以綠光指引進攻、藍盾標記防守，並用大白話解釋吃碰決策與自動結算台數，讓零基礎新手也能在牌桌上安心躺贏！

## 🏛️ 系統架構與設計模式 (Software Architecture)

本系統嚴格依循**「關注點分離（Separation of Concerns, SoC）」**、**「有限狀態機（FSM）」**與**「規則引擎（Rules Engine）」**設計，架構切分為三層：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        前端展示層 (Presentation Layer)                  │
│   - 全螢幕紅木墨綠絨布擬真牌桌 (Pure CSS3 3D 立體壓克力骨牌)              │
│   - 雀魂級全螢幕喊牌橫幅動畫 (「🀄 碰！」、「🥢 吃！」、「👑 槓！」)        │
│   - 四家桌面公開副露台 (金屬框清晰倒牌盤，電腦手牌真實縮水)              │
│   - 純 Web Audio API 物理敲牌聲合成 (零外部音效檔依賴，穩定不破音)        │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Event-Driven Interrupt
┌───────────────────────────────────▼────────────────────────────────────┐
│                    多代理人狀態機 (Multi-Agent FSM Layer)                │
│   - 檔案：app.js                                                       │
│   - 四人輪替狀態機：玩家 ➔ 下家(鍋底) ➔ 對家(楊姐) ➔ 上家(小亮)          │
│   - 非同步事件中斷機制：對手出牌時暫停主迴圈，搶佔觸發玩家吃碰決策列     │
│   - 巡目時間軸演化：前 4 巡安心理牌，第 5 巡後電腦合理聽牌與互抓放槍     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Pure Function In-Memory Call
┌───────────────────────────────────▼────────────────────────────────────┐
│                    核心領域演算法引擎 (Domain Logic Layer)              │
│   - 檔案：mahjongEngine.js (無副作用純函數，100% 可單元測試)             │
│   - 五面子一雀頭 DFS 回溯剪枝搜尋 (相容 17/14/11/8 張副露張數)          │
│   - 攻守雙模評估：進攻綠光 (何切/孤張優先) ｜ 防守藍盾 (場風現張安全牌) │
│   - 台灣麻將實戰台數規則引擎：自動結算底、自摸、門清、不求人、碰碰胡   │
└────────────────────────────────────────────────────────────────────────┘
```

## 🧠 核心技術亮點與演算法剖析 (Key Engineering Highlights)

### 1. 「五面子一雀頭」回溯驗證 (`isWinning` & `canFormMelds`)

台灣麻將胡牌規則為 **5 組面子 + 1 對將牌**。

- **邊界剪枝（Pruning）**：字牌（東南西北中發白）嚴格限制只能組刻，不可組順。
- **數牌邊界剪枝**：數牌 8、9 起頭張直接跳過順子嘗試。
- **副露動態適應**：`meldsNeeded = 5 - playerMelds.length`，手牌無論經歷幾次吃碰，演算法皆能無縫即時重算。

### 2. 攻守雙模決策與防放槍雷達 (Push/Fold Decision Radar)

- **進攻模式 (Offense)**：窮舉打掉每一張牌的後續聽牌門數。若尚未聽牌，優先鎖定手牌中單張落單的**字牌孤張（東南西北中發白）**亮起綠光，保全好搭子。
- **防放槍防守模式 (Defense)**：即時掃描四家牌河，將場上出現 ≥ 2 次的牌標記為藍盾安全牌 (🛡️)；未現張的 4、5、6 萬筒條標記為高危生張 (🔴)。若玩家打出聽牌對手的胡牌張，當場觸發放槍懲罰。

### 3. AI 吃碰新手決策支援系統 (Decision Support System)

當其他家出牌時，系統不只提供按鈕，更由 AI 進行深度推演並給予大白話解析：

- **強烈建議【碰/吃】**：推算出副露後手牌能直接進入聽牌狀態，按鈕套用強烈呼吸金光。
- **建議【過 (Skip)】**：當對手聽牌警戒時，警告副露會縮短手牌失去防守安全牌；或手牌漂亮時提醒保留「門前清」台數。

### 4. 實戰台數規則引擎 (Rules Engine)

自摸胡牌時自動觸發純函數計算，在結算面板上整齊列出明細：

| 台數項目 | 台數 | 條件 |
| :--- | :---: | :--- |
| 底 | +1 | 基本台 |
| 自摸 | +1 | 自行摸進胡牌張 |
| 門清 | +1 | 未曾吃碰 |
| 不求人 | +1 | 門清自摸加贈 |
| 碰碰胡 | +4 | 所有面子皆為刻子/槓子 |

## 🎮 系統核心功能展示 (Features)

- **四人擬真圍桌對局**：包含對家（楊姐）、下家（鍋底）、上家（小亮）真實坐鎮。
- **逼真的 136 張牌山**：Fisher-Yates 洗牌抽牌，物理餘牌摸完自動觸發荒莊流局。
- **桌面公開金色副露盤**：四家吃碰的牌大顆清晰地擺在桌面上，電腦蓋牌張數即時同步扣減。
- **雀魂級全螢幕橫幅特效**：任何人吃碰時，中央瞬間炸出「🀄 碰！」震撼視覺橫幅。
- **荒莊流局戰報覆盤**：告別原生 `alert`，以冷月銀黑卡片呈現局後 AI 戰術評語（聽牌防守成功 vs 牌效落後）。
- **上台演示專用按鈕 (Zero-Risk Demo Mode)**：一鍵預載楊姐副露倒牌與玩家絕殺五面聽，10 秒內保證展示自摸與 4 台明細清單，現場 Demo 絕不翻車。

## 💻 本機開發與執行 (Local Development)

本專案具備極高的便攜性與開箱即用特性：

1. **複製專案庫**：

   ```bash
   git clone https://github.com/W0X-1201/_se.git
   cd _se/Homework/Hw10(week11)
   ```

2. **啟動預覽**：
   - 使用 VS Code 開啟資料夾，於 `index.html` 按右鍵，點選 **「Open with Live Server」** 即可於瀏覽器啟動遊玩。
   - 或直接雙擊 `index.html` 以瀏覽器開啟。

3. **部署到 GitHub Pages**：在儲存庫 **Settings → Pages** 中，Source 選擇 `main` 分支並儲存，即可以上方 Live Demo 網址遊玩。
